# Album-Collection

 Overview

This is a Flask web application focused on classic R&B and soul albums. Users can browse an album collection, view album details, create an account, log in, and submit ratings and written reviews.

This is my first backend project using Flask.

 Features

- Album Collection: Browse a collection of R&B and soul albums.
- Album Details: View album titles, artists, and release years.
- User Registration: Create an account using an email address, username, and password.
- Login System: Log in using registered account credentials and Flask sessions.
- Album Reviews: Submit star ratings and written comments for albums.
- Dynamic Pages: Display album information and reviews retrieved from a SQLite database.

Technologies Used

- Python 
- Flask 
- SQLite 
- HTML 
- Jinja 

I was able to learn about routes and redirection, GET vs POST, and SQL queries. Flask sessions was the most intriguing part of this project. A lot of the mystery surrounding the web has been demystified by this project.
This project is not front-end 'flashy', since I wanted to focus mostly on backend
development, but I plan to make the design more appealing in due time. Soon, I want to give the search button on the album page more purpose.
